# mimai-web

Die öffentlichen Seiten von Mimai. Vorerst nur eine: der **Datenschutz**, weil App Store Connect
dafür eine Adresse verlangt und die App selbst keinen Server hat.

- https://get-ohoya.github.io/mimai-web/datenschutz.html

**Nicht hier bearbeiten.** Der Text steht im (privaten) App-Repository an einer Stelle
(`src/analysis/datenschutzText.ts`); die Seite wird daraus erzeugt
(`node scripts/datenschutz-seite.mjs`) und von dort hierher kopiert. Zwei Abschriften eines
Rechtstexts laufen auseinander, und zwar genau dann, wenn es darauf ankommt.

Sobald die eigene Website steht, zieht die Seite dorthin um; die Adresse in App Store Connect
wird dann einmal getauscht.
